Focus privacy policy

Effective date: September 27, 2026

Focus is a browser extension that blocks websites selected by the user, hides YouTube distractions, and protects its settings with a passcode.

Data processed by Focus

Focus processes the URLs of pages opened in the browser to determine whether they match the user's blocking rules. It stores the following information locally on the user's device:

  • Blocked website and page rules
  • Blocking schedules and extension preferences
  • The expiration time of a temporary YouTube distractions pause
  • Blocking counters
  • A salted cryptographic hash of the passcode
  • Failed passcode attempt count and lockout time

Focus does not store the passcode itself.

How the data is used

Focus uses this data only to block matching websites, apply schedules, hide YouTube distractions, display blocking information, and protect extension settings. Focus modifies YouTube pages locally and does not collect or store viewing history.

Data sharing and transmission

Focus does not transmit user data to the developer or any external server. It does not sell, share, or transfer user data to third parties.

Data retention and deletion

The data remains in the browser's local extension storage. Users can delete it by removing the extension or clearing its stored data.

Limited use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

Questions and issues can be submitted through the Focus issue tracker.
